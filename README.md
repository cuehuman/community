# CueHuman Community

CueHuman lets an AI agent ask a human for a decision, a file or form data, and get back an answer it can act on. When an agentic workflow pauses for a human, CueHuman sends the message, hosts a secure request form, and returns the human's answer to your agent.

## How It Works

1. **Your agent sends a request.** It names the human by email address or phone number and picks what to ask for: a choice from your options, file uploads, or a form.
2. **CueHuman reaches the human.** A link goes out by email, then SMS if needed.
3. **The human answers on a secure request form.** It opens on any phone or browser, with no login.
4. **Your agent gets the answer,** by webhook or when it reads the request.

## What This Repository Is For

This is the public home for developers building with CueHuman:

- **[Q&A](https://github.com/cuehuman/community/discussions/categories/q-a):** ask questions about the Agent API, your integration, the docs or your account.
- **[Feature Requests](https://github.com/cuehuman/community/discussions/categories/feature-requests):** suggest what we should build next, and vote on other ideas.
- **[Bug Reports](https://github.com/cuehuman/community/issues/new/choose):** report something in CueHuman that isn't working as it should.
- **[Show and Tell](https://github.com/cuehuman/community/discussions/categories/show-and-tell):** share what you've built.
- **[Announcements](https://github.com/cuehuman/community/discussions/categories/announcements):** API changes and new features.
- **[Integration code samples](samples/):** working examples to help you get started, beginning with [LangGraph](samples/langgraph/). Have one to share? See [Contributing](CONTRIBUTING.md).

## Before You Post

This repository is public. Never post API keys, passwords, or the names, emails or phone numbers of the people you contact. IDs like `org_…` and `req_…` are safe to share.

- For anything private, email [support@cuehuman.ai](mailto:support@cuehuman.ai).
- Report security problems privately, never in a public post. See [Security](SECURITY.md).
- Everyone taking part follows our [Code of Conduct](CODE_OF_CONDUCT.md).
