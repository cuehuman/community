# Security Policy

## Reporting a Security Problem

Please report security problems privately, never in a public issue or discussion.

- **On GitHub:** use [Report a vulnerability](https://github.com/cuehuman/community/security/advisories/new) on this repository's Security tab.
- **By email:** write to [security@cuehuman.ai](mailto:security@cuehuman.ai).

Include what you found, how to reproduce it, and the IDs involved (such as `org_…` or `req_…`). Never include API keys or the contact details of real people.

This covers the CueHuman service and the code in this repository.
